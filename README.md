# sprite-stack-object

A Claude skill for building sprite-stacked pixel art objects (cars, buildings, props) as slice sheets drawn in code, shown in a browser viewer you can turn.

- `SKILL.md`: the skill. It covers slice design, the sheet helpers, the software renderer, the viewer layout and the checks to run.
- `examples/sprite-stack-viewer.html`: a working viewer with two objects, a car (15 slices of 24 x 43 px) and a cyberpunk apartment block (56 slices of 36 x 36 px). Open it in a browser.

The art in the example is placeholder art generated by the page's own code.
