# sprite-stack-object

A Claude skill for building sprite-stacked pixel art objects (cars, buildings, ships, props) as slice sheets drawn in code, shown in a browser viewer you can turn and light.

- `SKILL.md`: the skill. It covers slice design, shape helpers for large sprites, the software renderer, the lighting pass, the viewer layout and the checks to run.
- `examples/sprite-stack-viewer.html`: a working viewer with four objects. Open it in a browser.
  - Car: 15 slices of 24 x 43 px.
  - Cyberpunk apartment block: 56 slices of 36 x 36 px.
  - Gunship: 48 slices of 104 x 152 px.
  - Breakwater heavy freighter: 48 slices of 208 x 304 px.
- `scripts/check.js`: checks a viewer page and writes a preview PNG per object. It needs only Node.

```bash
node scripts/check.js examples/sprite-stack-viewer.html
```

The viewer lights each frame in one pass from a per-pixel height buffer: surfaces facing the light brighten, taller parts shade what is next to them, and colours an object marks as lamps glow onto the hull and the ground. The renderer skips the empty space around each slice, so a 208 x 304 px object still draws in about 10 ms a frame.

The art in the example is placeholder art generated by the page's own code.
